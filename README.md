## Hi there 👋

Welcome to the **Scheduling Branch** of the **Virtual Reality (VR) Fitness App**! This repository focuses on the development and management of the scheduling module, where users can schedule, reschedule, and track their workout sessions seamlessly.

---

### **About This Branch**

This branch is dedicated to the **Scheduling Module** of the VR Fitness App. It includes all the code, documentation, and resources related to:
- **Scheduling Workout Sessions:** Users can select workout types, choose dates and times, and schedule sessions.
- **Rescheduling Sessions:** Users can adjust their workout plans by rescheduling sessions.
- **Tracking Session Progress:** Users can view the status of their sessions (e.g., Scheduled, In Progress, Completed) on a Kanban board.

---

### **Technologies Used**
- **Frontend:** React.js, Figma (for UI design)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Version Control:** Git, GitHub
- **Project Management:** Jira (for task tracking and bug reporting)
